# V3-04 MK-mini CAN Backend Implementation Plan

## Task 1 — Freeze source contracts (RED)

Add `tests/execution/test_v3_04_mk_mini_can_contract.py` covering:

- `mk_mini_protocol.py`, `mk_mini_command_state.py`, `socketcan_transport.py`, and `mk_mini_can_backend.py` must exist;
- package must not depend on `yhs_can_control` or `yhs_can_interfaces`;
- backend input topic is `/agt/chassis/backend/ackermann_command`;
- monitor mode is default;
- protocol TX period is 10 ms / 100 Hz;
- canonical feedback topics are present;
- launch installs and exposes backend configuration.

Run the execution contract and confirm RED because the backend files do not yet exist.

## Task 2 — Pure protocol codec (RED -> GREEN)

Create tests in `src/agt_chassis_mk_mini/test/test_mk_mini_protocol.py` and/or repository execution tests before implementation.

Golden vectors from the manufacturer manual:

1. D gear, 0 m/s, 0 deg, counter 1 -> `04 00 00 00 00 00 10 14`.
2. D gear, 1.000 m/s, 0 deg, counter 0 -> `84 3E 00 00 00 00 00 BA`.
3. zero gear/speed, -25.00 deg, counter 0 -> `00 00 C0 63 0F 00 00 AC`.

Add decode tests for:

- `ctrl_fb` signed steering, gear and vehicle mode;
- left/right wheel signed velocity and 32-bit signed pulse count;
- BMS voltage/current/capacity;
- BCC invalid frames;
- AliveCounter extraction and wrap helper.

Implement `agt_chassis_mk_mini/mk_mini_protocol.py` with pure dataclasses/functions and no ROS/socket imports.

## Task 3 — Pure command/gear fail-safe state machine (RED -> GREEN)

Test before implementation:

- positive speed selects D;
- negative speed selects R and transmits magnitude;
- zero fresh command retains active D/R gear;
- startup zero command stays P;
- D->R and R->D are blocked while valid feedback speed exceeds shift threshold;
- requested direction transition is released only after observed standstill hold time;
- stale command sends zero velocity without blind gear change when feedback is stale;
- stale command can park only after fresh feedback proves standstill for the configured hold period;
- steering is held while decelerating and centered once parked.

Implement `mk_mini_command_state.py` as a pure testable state machine.

## Task 4 — SocketCAN transport

Implement `socketcan_transport.py` using Python standard-library Linux SocketCAN only:

- PF_CAN / SOCK_RAW / CAN_RAW;
- extended-frame flag added at the transport boundary;
- bind to configurable interface;
- nonblocking receive;
- send 8-byte frames;
- transport exposes logical 29-bit IDs to the protocol layer;
- no shelling out and no privileged interface setup.

Add pure packing/unpacking tests that do not require a CAN interface.

## Task 5 — ROS backend node

Implement `scripts/mk_mini_can_backend.py`:

- subscribe `AckermannCommand`;
- `operation_mode=monitor|control`, default monitor;
- TX timer default 0.01 s;
- RX polling timer/nonblocking receive;
- explicit steering affine calibration and soft limit;
- `steering_calibration_confirmed` gate;
- command timeout feeds the pure state machine;
- decode feedback and publish canonical AGT topics;
- checksum/counter/transport/freshness diagnostic counters;
- best-effort safe shutdown command only when control mode and socket is healthy.

No TF publication.

## Task 6 — Configuration and launch

- `mk_mini_can_backend.py`.

Keep `mk_mini_adapter.launch.py` for adapter-only debugging.

Launch must not run `ip link` or require root.
